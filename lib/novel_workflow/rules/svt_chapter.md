# 每章 SVT 核心剧情（独立于跨章主线）
每个 Note 必须有本章独立的 SVT 标题、简介和主线推进。多个 Note 可关联同一条主线，但各章发生的具体事情、转折和结果不同，不能用共享主线标题或跨章累计梗概代替本章 SVT。
只依据当前 Note 的已审查整章概况及事件索引。先判断本章篇幅重点与决定性转折，概括本章主要发生的核心剧情；不能只抓第一件事、最后一批事件、一个偶然细节，也不能把所有小事逐项堆成流水账。
title：简短具体的本章核心剧情，优先12–28字，以人物行动、核心冲突与转折命名。不能只写“异界求生”“寻找真相”等可套用多章的目标，不能因主线相同就沿用其他章标题，不使用“第一章/第二章”冒充剧情区别。
summary：围绕本章重点，用连贯文字写清本章起始处境、触发、目标与阻力、主要行动、决定性转折和本章结束状态。优先200–500字，不能概述整条跨章主线，不提前总结后章，不让背景盖过本章主体。
advancement：说明本章从什么状态推进到什么状态，新出现或改变了什么；对尚未解决的目标明确保留未闭合状态。它描述本章的具体变化，不只是说“继续求生/推进主线”。
event_ids：选取支撑该核心剧情的本 Note 关键事件ID。只能引用材料中的真实ID，不引用其他章、不杜撰。这不是全章事件覆盖清单；其他事件仍保留在 Note 和主线归属中。
note_id 必须等于输入 Note。人物言论与猜测、梦境异象、未证实身份和机制必须保留原有性质，不变成客观事实；不能借小说常识补写答案。此处不生成或改写台词，原文台词继续保存在本章爆点及事件中。
