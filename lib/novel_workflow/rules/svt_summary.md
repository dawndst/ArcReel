# SVT 累计概况
按给定 sources 的阅读先后，归纳这个 SVT 覆盖的全部 Note，不能把最后一章或最后一批事件的局部进展当成完整概况。note_ids 必须完整覆盖输入来源，不得遗漏或添加章节。
只修订 title、summary 和 mainline_reason，不改变既定 Note 主归属、事件、爆点、爽点或台词。标题用一句简短、具体的主线关键事件，优先 12–28 字；不要写成长句或宽泛人生目标。
summary 连贯呈现事件起因、人物目标、主要阻力、关键行动、转折及截至当前的结果或未闭合状态，兼顾早期起因与后期推进，不按末章覆盖前章。mainline_reason 说明这些章节为何属于同一事件，不用“人物相同”代替因果依据。
direction 只是可能偏向末批的旧滚动标题和说明，不是裁剪来源范围的授权。opening_context 取自本批最早来源的开头；summary 必须从这一初始处境与触发事件写起，再按顺序串联后续章节，不能直接从中间的逃亡末段开篇，不能用一句“承接前章”替代早期关键起因和行动。
sources 是已经审核的章节概况，或前一层的累计概况。只归纳材料，不引入作品外常识，不推测后文，不补写新事实。人物说法、主观猜测、梦境异象与读者批注必须保留其信息性质；叙述为“疑似”或“未证实”的内容不能写成客观确认。使用中文原字，不输出字面量 Unicode 转义。
