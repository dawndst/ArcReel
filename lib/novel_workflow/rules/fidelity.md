# 事实、推测与对白归属
逐条区分正文明确事实、人物说法、人物推测、梦境或幻象、改编建议；使用 claim_type、perspective、source_kind 字段（当输出结构包含这些字段时）。旧材料缺少分类意味着未判定，不等于事实。人物声称、怀疑、看不清、似乎、梦中所见，不能升级为客观事实。
明确属于读者、译者的批注或附加评论不是故事事实；括号、引号、脚注形式本身不能判定来源，作者正文中的括号叙述仍可能是剧情依据。批注透露的姓名、身份和后续情节不得用于当前揭示时点。保留真实正文，不以简单删除全部括号的方式处理。
摘要、SVT、爆点和场镜必须继承来源的确定程度。身份未确认时保持模糊身影或主观视角，不能绑定为身份已证实的角色出场。原文引句存在只能证明引用正确，不能证明人物动机、身份或因果推论正确。
跨章新证据确认早期疑点时，保留早期疑点，记录新证据的揭示 Note；不得倒写早期人物已经知道答案。保持原文事件先后，不把回忆、猜测和梦境当成实时发生。
输出前逐项核对身份、动机、事件顺序、因果、说话人；只改不受证据支持的结论，保留支持的内容。不能用确定措辞掩盖无法确认的内容。
对白逐字保留。Note 抽取的 dialogues.speaker 未知时写“未明确”，不得填猜测姓名。在场镜素材的 utterances 中，dialogue 的 speaker 应使用输入人物资产名；若原文未明确归属或输入缺少对应人物，speaker=null 留待人工确认，不猜成主角，不伪造人物名，不将角色对白改为 voiceover，不因缺说话人删除关键台词。voiceover 只用于真正的叙述旁白。场镜素材可以保留待确认对白，正式制作脚本必须先确认。

所有含信息性质字段的条目必须显式填写 claim_type、perspective、source_kind，不能省略后依赖默认值。unverified 或 unknown 必须写 uncertainty_reason，说明是缺少上下文、指代歧义还是依据不足，不把“字段没填”写成小说本身有疑点。
复合结论中混有事实和推测时，拆分或明确限定推测部分；不能把整条默认标成 fact。声称、回忆、梦境的发生可以是真实叙述，但其内容不自动成为现实事实。人物知道、观众得知、故事中实际发生是三个不同时间，不互相代替。
已读记忆只帮助检索和辨认，不能替代当前结论的证据。观察到伤口不等于永久伤残，情绪变化不等于关系永久破裂，未描述服装不等于衣着破旧。当前文本没有提到不等于此前不存在。
