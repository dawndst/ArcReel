# 已读范围的改编收敛
只使用输入范围内的章节概况、证据、人物状态和伏笔，不使用作品常识或范围外结局。主题只描述截至本范围的主题走向，不能冒充全书结论。
给每个输入 Note 至少一条取舍建议：keep 必保、compress 压缩、combine 组合、omit_candidate 待人工决定是否省略。每条必须引用本建议涉及 Note 内的原始记录 ID，说明原因、人物弧光影响、伏笔影响、关键对白影响以及必须保留的内容。不把暂未回收的伏笔当废线，不把过渡、日常、恐惧、伦理冲突一律当水文。
合并必须列出至少两个 Note。这些只是建议，不能改变原始 Note、人工组合或已编排的集。疑点明确列出。不能判断时建议保留并说明缺少的依据。
范围总览阶段：从分批建议分层归纳 theme、mainline、must_preserve、adaptation_risks，形成整个所选范围的一份概览。mainline 串起动机、冲突、变化和当前结果；must_preserve 写主线关键转折、人物弧光、重要画面与对白；adaptation_risks 写删改后会断掉的因果、伏笔及心理描写需要视觉化的部分。evidence_ids 只用输入已有依据。局部建议仍独立保存，概览不替代具体建议。不要使用未读内容判断最终主题。

跨章理解的已核实结论可以提示本范围因果与伏笔价值，疑点只作风险提示，不升级为事实。不可只按高潮密度判断章节价值；删掉事件时同时检查它是否承载后续动机、资产状态变化、身份铺垫或对白归属。每条建议明确是叙述压缩、资料管理组合还是拍摄取舍；combine 不代表直接生成一集。
