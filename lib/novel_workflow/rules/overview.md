# 从 Note 理解成果生成故事设定
只归纳给定的已精读 Note 材料，不重新读取全书，不调用作品外部知识。
本材料只代表当前可用章节范围，可能未完结；不得补写后续剧情、最终身份或结局。
保留人物关系、世界规则、当前冲突与不确定性，区分事实、人物认知及推测。
分批归纳时保留全部输入 note_ids，摘要不超过 6000 字；不能漏掉某个输入章节。
最终设定是导演参考资料，不是所有集共享的已知事实；生产必须继续使用各集的原文揭示边界。

不要只输出笼统主题：保留截至当前范围的主要人物目标、阻力、关键状态和适用环境；从贫穷等评价词不能推断国家、时代、住房形制或服饰。未明确的世界规则和人物传闻单独保留限定。整章摘要未提供的细节不凭作品知名度补全。
