# Note 资产登记与编号

每章精读结果落盘后，把有原文证据的人物、场景和道具登记到 ArcReel 原生项目资产；历史有效缓存也在精读任务收尾同步。无需第二次调用模型。过期阅读结果不参与登记。

- 人物 CHR、场景 LOC、道具 PRP；项目内各自递增，删除不回收号码。
- asset_id 标识制作资产，entity_id 标识人物本体；人物衍生形态独立编号，共享 entity_id。
- 身份键由类型、名字、identity_scope 构成；未限定身份的常见泛称按 Note 分开。不会自动用别名或跨章身份结论强行合并。身份不确定时由创作者使用原生资产合并操作确认。
- Note 中的记录 ID 仍标识证据；project.json 的 note_asset_links 将证据记录关联到稳定资产 ID。阅读文本不因登记被改写。
- 后续原文明确提供 variant 时，登记到原生 derivatives。年龄、变身、伤势须有本段证据；普通情绪变化不需要外观衍生。已有精读缓存不会被追溯推断形态。
- 原生改名保留 ID 和编号；人工合并迁移 Note 引用。并为新衍生时保留原制作资产编号；并入已有资产时使用保留方编号，旧号不复用。删除不因重读被自动复活。
- Note 名称显示编号，可点击进入对应资产页，悬停查看本章描述和原文依据。资产库与 @ 候选显示同一编号；@ 可以按编号搜索，插入仍为原生 `@[人物/形态]`，保持生成链兼容。

生产提示词只使用选定 Note 的原文和允许范围内的理解结果，不注入全局资产的后文描述。资产库是面向创作者的全局资料视图，不等同于某一集允许揭示的剧情。

当前只对相同名字和身份范围自动复用。名字/范围由模型写法不一致时可能产生独立条目，应使用原生合并确认；没有启用模糊匹配去猜测身份。编号代表登记，不代表图片已审核或资产已经可用于成片。

## 首次出现于哪个 Note

人物、场景、道具及人物衍生形态的 `first_note` 保存 Note ID、原文章节顺序和章节标题。按当前有效、已生成 Notes 的顺序取最早出现位置，不按资产登记或任务完成时间排序；尚未阅读的章节不作推断。后来补读更早章节时重新计算，本体与衍生形态分别保留首次位置。人工合并保留更早的来源。

资产卡片、详情及衍生行显示“首次出现：Note 001 · 章节标题”，可点击返回指定 Note。悬停可看完整标题及范围说明。没有 Note 依据的手工资产不伪造来源。

资产编号表示登记身份，首次 Note 表示原文位置，两者顺序可能不同。首次位置也不等同于形态适用区间或读者得知真实身份的位置，不能代替状态时间线与揭示边界。
