# 集、场、镜头与 SEG

新生成的剧情演绎脚本按「集 → 场 → 镜头」组织。一个镜头超过15秒，拆为同镜头的 SEG1、SEG2 等生成片段；每段都必须不超过15秒，同时满足视频供应商的时长档位。若供应商最高只支持8秒，则按8秒以内分段。没有可用档位时，生成入口明确报错，不能默默使用超长档位。

例如第1集第2场第3镜头需要24秒，模型支持12秒时：

- `EP01-SCN002-SH003-SEG1`：12秒，前半段动作和对白。
- `EP01-SCN002-SH003-SEG2`：12秒，承接前一段结束状态，继续后半段。

同一连续时空的一场戏共用场号；换机位、景别或剪辑切点应换镜头号，不能冒充同一镜头的 SEG。未拆段的镜头不显示 SEG 后缀。场号不等于场景资产编号 LOC。

持久化字段为 `scene_number`、`shot_number`、`segment_number`。为了复用原生生成、素材和版本记录，执行列表仍为扁平 `scenes`，每条是一个可生成片段；原生 `scene_id` 保持唯一，只作内部执行定位键。显示编号由三层字段生成，不再把列表位置当作叙事镜头号。

AI 规划必须提供场号和镜头号，并为每个 SEG 分配独立画面、对白、时长和原文依据。校验拒绝超长片段、混合有/无层级、重复或缺号 SEG、被其他镜头穿插的 SEG。图片与视频提示词编写接收同一层级和连续性指令；跨场参考图依叙事场号断开。

内容确认页与正式分镜详情可以编辑 SCN/SH/SEG。新增空白镜头承接当前场，使用新镜头号，放在锚点镜头所有 SEG 之后。删除片段整理剩余 SEG 编号，但不改已有素材的执行 ID。旧脚本不猜测补场：需要使用新规则时重新规划。

左侧边栏上方为成片分集列表，下方为项目概览、小说理解与改编及资产导航；展开和折叠状态均保持这个顺序。

## 未组集素材库的显示编号

素材库按 Note/原文分块的剧情顺序展示连续 SCN-001、SH-001 编号。筛选不重编号，后续补齐更早剧情时展示编号重新计算。固定来源ID保留在原文依据中用于历史追溯，页面编号和固定ID不能互相代替。导演组集保留固定ID关联，再生成独立集内场镜层级。详见 [编号与制作字段核查](shot-list-production-review.md)。
