## 本轮修复

### 生成与回查稳定性

原始第三章片段重试仍出现503；把相同规则、原文、记忆和结构分别放入 JSON 字段后，正式读取恢复。未据此推断供应商内部根因，也没有更换默认模型。

引文定位允许 EPUB 排版空白与摘录外层引号差异，不允许改词、拼接、添加省略号或含糊匹配。跨章回查中的片段编号写错，只在已提供原文中存在唯一匹配时修正。缺少锚点 Note 的关联进入待核实，不作为确认关系。

跨章理解最多并行三个独立单元，逐单元落盘；失败保留其他单元的付费结果。截断只在明确允许的理解/场镜步骤提高输出预算，仍受模型能力及48,000上限约束。普通章节抽取保留原有分块策略。

### 对白缺少说话人

素材库与正式制作脚本使用不同约束。素材库可保存 `dialogue + speaker=null`，正文和对白类型保持原样；页面显示“说话人待确认”，可核对原文后选择人物资产。正式组集必须完成归属，服务端也会检查。不会默认为主角、改成旁白或删除台词。

确认说话人保留历史记录，并校验镜头版本；修改后既有组集会因来源变化要求复核。

### 事实、推测与原文语义

新增独立可替换规则 `lib/novel_workflow/rules/fidelity.md`，项目可在 `novel_workflow/rules/fidelity.md` 覆盖，工作台“规则提示词”页面可查看。规则注入 Note、章节归纳、跨章理解、SVT、场镜以及原生制作准备请求。

证据条目新增 `claim_type`、`perspective`、`source_kind`，区分正文事实、人物说法、推测、梦境/幻象、改编建议和未判定资料。没有这些标记的旧资料显示“确定性未判定”，不自动标为事实。人物说法、推测和梦境必须记录认知主体；批注不能标为正文事实。

明确标为推测/人物说法的身份关联不会作为已确认的跨章事实传入下游，也不用于自动登记确定资产或归并别名。后续揭示继续受 Note 时点约束。

新增场镜语义审核：直接对照当前原文，而非只检查引用字符串。审核建议限定为场镜标题或画面描述的局部修订，带原文、理由、修订前后文案。工作人员逐条采用，保留旧版；对白/结构等无法安全自动修订的问题留为疑点，可在核对当前片段后记录依据处理。该审核不是“模型保证正确”，误报处理也有记录。

场镜草稿和语义审核分别缓存。审核失败重试不会重新生成已经保存的场镜草稿。

## 仍存在的旧产物质量问题

没有为应用新规则而全量重读或改写旧产物。此前审核还发现：第二章导览把疑似人物写成确定身份；部分 SVT 的事件顺序、车夫动机需要修订；理解关联中有一条把冗佑的附身对象解释成宝剑，证据不支持该结论；阳子存在9个身份根记录。当前局部修订不等于这些旧问题已全部解决。

新增分类与语义审核用于后续生成及局部处理，不能追溯性地为旧数据背书。规范身份与年龄、形态、伤势变体仍有必要，不能仅凭同名自动合并。
