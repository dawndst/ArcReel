# 复审与人工确认的放行规则

生成完成、模型复审、人工批准是不同状态。普通提示不能要求工作人员重新读完整本书。

- **可以继续**：普通疑点、改编取舍和拍法建议、参考时长提示不阻挡参考组集。
- **只限制相关内容**：无效来源、结构或身份因果冲突限制相关 Note/场/镜，其他有效成果可继续。
- **正式交付前完成**：可先建立参考分集、导出草稿；正式交付再核对所选内容、资产形态、图片和编导确认。

| 检查 | 由谁处理 / 模型调用 | 对下一步影响 | 入口与解除条件 |
|---|---|---|---|
| Note 提取与原文校验 | 模型自动提取、语义复审；代码核对引用和结构。 | 未通过时，仅该 Note 的后续生成需等待；其他完成的 Notes 可继续。 | 任务详情查看定位并继续该章；成功片段会复用。 |
| 普通疑点与未揭示信息 | 编导按影响选择核对；查看依据不调用模型。 | 不影响当前身份或因果的疑点不阻挡，不必为清空提示猜答案。 | 在 Note 或跨章理解保留未知，按定位核对相关原文。 |
| 跨章身份与因果结论 | 开启理解层时由模型回查；编导处理高影响冲突。 | 影响身份或因果的冲突只限制相关 Note 的 SVT/场镜；对白解释疑点可保留原句继续做素材。 | 跨章理解中核对结论和制作约束；只需当前阅读范围，不必读完小说。 |
| 本章 SVT 与爆点完整度 | 模型生成、代码核对事件和原句关联。 | 每 Note 需有本章核心剧情与唯一主归属 SVT；共用主线不等于共用本章内容，也不等于一集。 | SVT 页查看本章标题、推进、爆点和台词；按当前章补齐或更新。 |
| 场镜生成与来源校验 | 模型逐场生成，程序按 ID 回填原句、资产和位置。 | 失败只留在相关场；成功场可继续选择。已有草稿不等于整章完成。 | 继续未完成场面；复用候选和成功镜头，不重新读取整章。 |
| 场镜原文复审与修订建议 | 模型自动提出局部建议，编导决定采纳或修订。 | 建议不阻挡建立参考集；正式交付前处理所选镜头的事实与因果问题。生成不代表人工批准。 | 在对应场或镜采纳修订、编辑内容，或记录有依据的保留决定。 |
| 资产本体与当前形态 | 编导选择关联，保存不调用模型。 | 图片未确认不影响参考集；文字本体完全缺失时先关联或创建待定资产。正式交付前确认当前年龄、形态、伤势与场景。 | 在 Note 资产卡关联本体/形态；确认后自动回填待定镜头引用，无需重生成故事。 |
| 对白说话人与发声角色 | 编导分配或登记待定角色；AI 归属辅助为可选模型调用。 | 匿名/路人可登记待定发声角色后建立参考集；正式交付需可用角色和声音设定，不强求原著未给的姓名。 | 在对应镜头分配已有角色，或登记待定发声角色；不改写原话。 |
| 改编取舍、造型与观众理解辅助 | 编导按需处理；主动点击 AI 辅助会调用模型并确认。 | 不要求把建议全部采纳、逐项清零或每项写理由；不阻挡建立参考集。 | 只处理影响当前表达的项；观众理解辅助只看所选视听内容，不代替编导批准。 |
| 参考时长、节奏与首尾画面提示 | 编导调整；没有语速预算校验。 | 参考时长不是最终视频时长，普通提示不阻挡组集。连续 SH 总计不超过 15 秒时归为一个执行段。 | 按创作需要调整；超过 15 秒才拆 SEG，实际生成时再选择模型时长档位。 |
| 图片参考确认 | 工作人员确认；上传和确认不调用模型，主动生图会调用模型。 | 图片未完成不妨碍参考集；正式交付需确认所用图片符合本场当前形态。 | 资产库上传或生成图片后确认；图片变更需重新确认。 |
| 最终编导确认与正式交付 | 编导确认故事、节奏、连续性与必要问题处理。 | 可先建立参考集、导出草稿；正式交付前完成必要资料和确认，硬错误不能直接签字跳过。 | 组集预览 → 建立参考集 → 确认资产与内容 → 正式导出。 |

任务上限可在阅读设置中调整。组集最多 300 镜；本集所选原文依据去重后最多 60,000 个字符。达到时可减少镜头或拆成多个参考集，不限制全书章节数。

界面入口：小说理解与改编 → 工作流程 → 复审与人工确认。对应场镜和组集预览同步标注参考组集与正式交付的差别。所有主动模型调用操作保留二次确认。
