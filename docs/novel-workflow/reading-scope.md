# 按未完结小说进行部分阅读与制作

导入原文并建立章节 Note 后，在「当前可用章节」中选择起止章节序号，也可逐章勾选。首次精读自动将所选章节设为当前可用范围；无需先读完整本书。后续精读新章节会追加到范围中。可用范围与本次任务选择分开：需要缩小范围时，点击「以所选章节设定可用范围」。选择和设置范围不会调用模型。

只有当前可用范围内的原文可以参与跨章回查；范围内未精读章节可以被定向检索。累计资料排除范围外的阅读结果，使用范围外依据的跨章报告失效。原有阅读文件仍保留，扩大范围后按依据有效性复用。未解线索保持待续，不要求补读范围外原文。范围配置保存在项目 novel_workflow/scope.json，检索缓存按来源和范围隔离。

选中章节精读及理解完成后，可以提炼 SVT、请求改编建议、生成场镜素材，再由导演勾选场和镜组成一集。一章也可以生成候选场镜；人工 Note 组合只管理资料。生产只检查选定镜头的章节及其依据，不检查整本书是否读完。AI 不自动合并 Note。

历史项目尚未设置范围时保留已有访问范围；首次精读会建立明确范围。此功能支持分批阅读已导入的书；更换或追加原文文件仍需重新预览章节索引，并由既有来源有效性检查决定哪些产物需要更新，不承诺来源变更后所有生产绑定自动沿用。
