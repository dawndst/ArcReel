# Note 工作流入口审计

剧情演绎项目统一使用 Note 工作流。旧 AI 分集规划已删除，不再通过开关回退。

| 入口 | 当前行为 |
| --- | --- |
| 故事设定按钮、项目管理器、旧 overview 包装入口 | 统一进入 `novel_workflow.overview`，只汇总明确可用范围内且仍有效的精读 Notes |
| 上传小说后的自动生成 | 不再自动生成故事设定；先识别章节目录、指定章节并 AI 泛读生成 Notes |
| 长范围设定归纳 | 单条材料切片、18k 字符预算分批、层级归纳及落盘缓存，不把全书原文送给模型 |
| 设定保存 | 复核原文、阅读结果、范围、规则；缺少前置条件返回可操作的 409，不伪装为供应商错误 |
| 旧全书理解 ensure | 拒绝执行，不隐式读取范围外章节 |
| 脚本及分镜规划 | 必须具有导演组集的 note_source，使用 NoteProductionGuard；缺少绑定明确拒绝 |
| Note 任务 | 使用独立 text_novel_workflow 类型、novel-workflow 槽位和停止接口；只提交指定章节 |
| 旧 AI 分集、重规划、旧评估排队任务 | 接口、Agent 工具、队列处理分支和算法模块均已删除 |
| 原文手工切集、合并、采用重规划候选、重置 | 原文切集、重规划与重置实现已删除；Note 管理组合与导演组集各自独立 |
| 工作流状态和 Agent 技能 | 不再推荐原生 AI 分集或自动创建集，指向 Note 工作台与导演选镜 |
| 旧理解状态/项目设置 | 当前模式不显示旧失败进度、不展示无效的旧理解层开关 |
| 规则查看页 | 展示新故事设定规则；旧流程规则仍可查阅但不参与当前模式 |

旧分集规划不能重新启用。解说和广告保留已有集的生产能力。`novel_understanding.store` 中的 hash、时间等通用函数，以及停止信号的复用，不代表调用了旧全书阅读流程。

当前故事设定仅是当前范围的导演参考。正式生产继续按每集 Note 揭示边界提供材料，不把范围末尾的设定回灌到早期镜头。

导入后的入口：小说理解与改编 → 识别／更新章节目录（不调用 AI）→ 指定起止章节或勾选章节 → AI 泛读并生成 Notes。目录中的待读行只是占位，生成后才有章节梗概、资产、人物变化与事件线索；跨章精读回查仍是独立步骤。
